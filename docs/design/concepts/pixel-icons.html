// 画法

  • 画板与格子：图标栏、顶栏、标签栏的图标都在 16 × 16 以内的画板上，1.5 点一格（Retina 上是 3 个像素，边缘是整的；iPhone 3 倍屏上取整像素一格）。看得出格子，才是像素画，不是细线。
  • 只用墨色的六档：高光、墨、中、暗、深、底。不上颜色；浅色背景下六档反过来（最深的墨到纸的暗部）。
  • 层次靠明暗：近的、凸起的亮，远的、凹下去的暗。凸起的块（方块、滑杆的钮、加号、锁身）上边和左边一格高光，下边和右边一格暗色；窗口类的图标用墨色描边，里面是深色的屏幕或面板；应用标记的三条线一条比一条暗。
  • 硬阴影：右下偏一格的暗色影子（和文字标、应用标记现有的做法一致），可关。
  • 状态仍然有颜色：状态方块的绿、橙、红是在说状态，照旧，只是多了亮边和暗边。选中仍是信号粉的竖线。没选中或不可用的图标整体压暗。盲文转圈不动。
  • 不变的：图标的意思和位置、“一个图标一个意思”。菜单栏里的图标按系统规定是单色模板图，不换。
