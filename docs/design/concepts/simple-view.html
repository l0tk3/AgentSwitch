Simple View

终端的简略视图，iPhone 与 Mac 两端，Pixel 与 Classic 两种外观。接手前那个只读的记录页不变，按下 Resume 之后不换到终端的屏幕，而是留在同一页上，把回复、确认、提问、按键这些补进来。终端页能做的事这里都能做；程序自己画的界面随时切回终端。概念稿，2026-10-07。

// 比接手前的记录页多了什么

  • 回复：终端页的同一个输入框——+ 附件、/ 命令、锁（加密发送）、像密码时先问。
  • 需要你时：确认卡和提问卡排在记录的末尾，答完收成一行，留在记录里。
  • 正在做什么：末尾一行写当前的工具与已用时间，子代理另起一行；忙的时候发送键变成 ■，按下打断。
  • 程序自己的界面（选模型的菜单、登录、任何没被认成卡片的提问）：一张 Prompt 卡，画出屏幕最后几行，按键条自己出来，旁边 Open Terminal。
  • 其余：Earlier 取更早的记录，过长的消息 Show More，往回翻时 ↓ Latest，代码块 Copy，链接点开与长按菜单，⋯ 里改名、关闭与换视图。

// MAC 上不一样的地方

  • 在一块分屏里。记录排成中间一栏（最宽 700 点），输入框在这一块的底部、同样宽。分屏时每一块各有各的视图，块的标题栏右边切换；只有一块时切换在窗口顶栏的右边。
  • 先看再接手。Mac 上现在点列表里以前的会话只有 Resume 和 Delete，没有记录页。这一稿里点它就在这一块里打开只读的记录，底部 Resume，和手机一样。
  • 没有按键条。有真键盘：输入框里 ↩ 发送、⇧↩ 换行、忙的时候 esc 打断。出现 Prompt 卡时键盘直接给程序（切到 Mac · Prompt，按方向键和回车试试）。
  • 确认卡带快捷键：↩ Allow，esc Deny，和终端视图里的卡片一样。
  • 附件：+、粘贴，或者把文件拖到这一块上（终端视图已有的拖放）。
  • 改名、关闭、单独开窗口照旧在列表那一行的菜单里；状态栏右边原来写终端尺寸的地方写 Simple，锁仍是 Encrypt & Send。
  • 主窗口固定深色（ui-v0 §8），所以 Mac 上没有浅色；Classic 用系统的蓝和它自己的词（Working、Needs You、Ready、Ended）。

// 需要你定的

  1. 默认进哪个视图。建议：有会话记录的 agent，Resume 和新建之后默认进简略视图；每个终端记住上次用的那个，两端各记各的。
  2. 换视图的入口放哪。手机上现在画的是导航栏右边一个图标（>_ 去终端，≡ 回来），⋯ 里也有一项；Mac 上是顶栏右边的两格开关。手机上也可以只留 ⋯ 里那一项，顶上更干净。
  3. 手机的按键平时收起。现在放在 + 菜单的最后一项，程序等按键时自己出来。也可以在输入框旁常驻一个键盘图标，多占一格。
  4. 手机的深浅色。简略视图跟随手机的外观（和现在的记录页一样）；终端视图仍然固定深色。
  5. Mac 上点以前的会话先看记录。这是新行为（见上）；不要的话保持现在的悬停 Resume。

// 做的话，服务要补的

  • 记录现在每 10 秒取一次，每条消息截到 2000 字。简略视图要跟着终端的事件更新，并能取一条消息的全文。
  • “正在做什么”现在只有 Busy、Waiting 和子代理行；当前工具与命令要从会话记录的最新一条或 hook 里拿。
  • Prompt 卡要服务给出屏幕最后几行的文字。终端页已有整屏画面，这里只取尾部。
  • Claude Code、Codex、OpenCode、pi 都有会话记录，都能用；没有记录的程序只有终端视图，不显示切换。
