Simple View

iPhone 上终端的简略视图。接手前那个只读的记录页不变，按下 Resume 之后不换到终端的屏幕，而是留在同一页上，把回复、确认、提问、按键这些补进来。终端页能做的事这里都能做；程序自己画的界面随时切回终端。概念稿，2026-10-07。

// 比接手前的记录页多了什么

  • 回复：终端页的同一个输入框——+ 附件、/ 命令、锁（加密发送）、像密码时先问。
  • 需要你时：确认卡和提问卡排在记录的末尾，答完收成一行，留在记录里。
  • 正在做什么：末尾一行写当前的工具与已用时间，子代理另起一行；忙的时候发送键变成 ■，按下打断。
  • 程序自己的界面（选模型的菜单、登录、任何没被认成卡片的提问）：一张 Prompt 卡，画出屏幕最后几行，按键条自己出来，旁边 Open Terminal。
  • 其余：Earlier 取更早的记录，过长的消息 Show More，往回翻时 ↓ Latest，代码块 Copy，链接点开与长按菜单，⋯ 里改名、关闭与换视图。

// 需要你定的

  1. 默认进哪个视图。建议：有会话记录的 agent，Resume 和新建之后默认进简略视图；每个终端记住上次用的那个。
  2. 换视图的入口放哪。现在画的是导航栏右边一个图标（>_ 去终端，≡ 回来），⋯ 里也有一项。也可以只留 ⋯ 里那一项，顶上更干净。
  3. 按键平时收起。现在放在 + 菜单的最后一项，程序等按键时自己出来。也可以在输入框旁常驻一个键盘图标，多占一格。
  4. 深浅色。简略视图跟随手机的外观（和现在的记录页一样）；终端视图仍然固定深色。
  5. Mac 上要不要同样的视图。这一稿只画了手机。

// 做的话，服务要补的

  • 记录现在每 10 秒取一次，每条消息截到 2000 字。简略视图要跟着终端的事件更新，并能取一条消息的全文。
  • “正在做什么”现在只有 Busy、Waiting 和子代理行；当前工具与命令要从会话记录的最新一条或 hook 里拿。
  • Prompt 卡要服务给出屏幕最后几行的文字。终端页已有整屏画面，这里只取尾部。
  • Claude Code、Codex、OpenCode、pi 都有会话记录，都能用；没有记录的程序只有终端视图，不显示切换。
