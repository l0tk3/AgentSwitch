// 这页画的是什么

  • 身份是席位：每个成员一个不变的名字（@daemon），旁边是它的 agent 标记；行尾的小色点是它所在的配置（Default 不标）。点名字出名片：agent、模型、配置、节点、目录、权限模式、谁拉进来的。
  • 谁发给谁看得见：正文里的 @名字 是收件人；被引用的那条显示在消息上方；带 @ 的消息下面一行是每个收件人的投递状态。
  • 投递状态：Sent（写进房间）· Queued（对方在忙，这一轮结束再送）· Delivered（交到手上）；对方处理完这一行就消失。对方已结束时是 Ended，红色。
  • 发给你、还没看的：行左侧一条琥珀色——琥珀只表示“等你处理”。看过（切到这个房间）就没有了。
  • 成员的状态用终端的那一套：像素外观 Busy · Waiting · Idle · Exited（转圈、键、空心键），经典外观 Working · Needs You · Ready · Ended（转圈、圆点、空心圆）。
  • 多轮没有你：两个 agent 之间连续往返到 6 次，提醒你一声（顶上一条、房间列表里一个标记、手机上一条通知），不打断它们。要停由你点 Pause；暂停时消息照写，不投递。
  • 一行只写谁和什么时候：agent 是名字旁的图，模型、节点、目录在名片里；投递状态只在还没送到或送不到时出现，都处理完了就不写。
  • 置顶笔记：房间名下面那一段，所有成员能读能改（第一版的“临时协作区域”）。

// 头像

  • 每个席位一张 5×5 的图案，左右对称，由名字算出来：同一个名字在哪台设备上都是同一张，不用存、不用选。
  • 十五个格子决定一张（三列五行，另两列是镜像），去掉太空、太满、整排整列一样的，剩下两万多种；同一个房间里再保证两两至少差六格。
  • 只用墨色：颜色留给配置和状态。agent 是名字后面那个小图标。你自己是固定的 YOU。
  • 两种外观是同一张图案，像素外观画方格，经典外观画圆点。下面是 48 个名字各自的样子，切换上面的 Pixel / Classic 一起变。

// 两种外观各自怎么画

  • Pixel（ui-v0 §7）：等宽、方角、1px 实线；分组标签 // Label；选中是行左 3px 信号粉竖条加序号；按钮 [ Word ]；单选 <x>、复选 [x]；浮层是 1px 墨色框加抖动硬阴影；agent 是 5×5 像素图；提到人是加粗带下划线，提到你是反色块。正文不加工，用系统字体。
  • Classic（§8）：系统字体、圆角、线性图标、标准按钮、圆点状态、数字角标、柔和投影；强调色是蓝；提到人是浅蓝底的胶囊。主窗口仍是一整块黑；iPhone 随系统深浅。
  • 两种外观共用同一批页面、同样的词（少数状态词按 §8 已定 2 换），只换画法。
