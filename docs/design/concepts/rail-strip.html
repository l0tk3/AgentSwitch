// 先例

  • Discord 服务器列表：贴在最左边缘的白色半圆条，只有一种颜色，用高矮说悬停与选中。——这里的形状。
  • VS Code 活动栏：当前项是边上一根细线（1.40 起）。
  • Windows 11 任务栏：图标下的小横条；要你处理时不再一直闪，闪几下后停成红条，微软称 “a calming treatment that minimizes the impact of unwarranted distractions”。——颜色只留给要你处理的事。
  • Arc、Notion、GitLab：收起后不留一栏，指针碰到左缘（GitLab 是 8 px）侧栏浮出盖在内容上，移开收回。——这里的浮出。
  • 苹果的睡眠指示灯：每分钟 12 次、模仿呼吸的明暗。——呼吸要慢。
