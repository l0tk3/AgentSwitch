设置 › Agents：每个 agent 一组，每行一个安装。左边的单选是 AgentSwitch 用哪一个（和命令行里用哪个无关）；Stable 装在各家自己的位置、命令行里就是 claude codex opencode pi，删掉 AgentSwitch 不受影响；Beta 与 Pinned 在 AgentSwitch 的版本库里，Beta 在命令行里是 claude-beta 这样的名字。页面可以直接点。

来源　Stable 原位安装（各家官方位置，自己会更新，也可以在这里点 Update）；Beta 测试通道，版本库里只留一个版本，更新即替换；Pinned 你指定装的某个版本，不更新；ChatGPT App 只有 Codex 有，随 App 更新，不能删；Other 别处找到的（Homebrew、npm、OpenCode v1），只列出、不在这里管。

有更新　那一行跟的通道有比它新的版本时出 Update → 版本，侧栏的 Agents 带数字。只提示，不自动装。Claude Code 的原位安装跟它自己设置的通道（这台 Mac 跟 latest），所以比 stable 新不算有更新。

删除　先弹确认：删哪个版本、哪些路径、多大；登录、配置和会话记录不受影响。正被 AgentSwitch 选用的那一行写明删除后改用哪个；有终端或任务在用时不能删。

不留垃圾　下载放临时目录，成功、失败、取消都删掉；各家自己攒下的旧版本单列一行 Old Versions，可以一键清掉；页面底部写版本库的位置和总大小。
