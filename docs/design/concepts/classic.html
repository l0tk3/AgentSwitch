// 经典外观怎么画

  • 字：界面文字一律系统字体（SF Pro、苹方）。等宽字只留给终端屏幕、代码块、命令和路径；不再有等宽短词。
  • 形：圆角。控件 6–8，卡片与浮层 10–12，气泡与输入框 14–17；阴影是柔和的投影，不用抖动硬阴影；1 点细线只作分隔。
  • 图标：线性图标，18 点画板、1.5 点线宽、圆头圆角，线落在半像素上（Retina 下边缘是整的）。原生实现直接用 SF Symbols；只有应用标记自己画：还是“一分三”的构图，方块变圆角，折线变曲线。
  • 状态：圆点——绿是空闲 / 正常，橙是等你处理（外圈缓慢呼吸），红是失败，灰色空心是已结束；进行中是系统的转圈。数量用数字角标。
  • 按钮：标准按钮。主操作填强调色，次操作浅底细边；快捷键写成按钮里的小字。不用 [ Allow ]。
  • 标题与列表：常规小标题（半粗、次要色）代替 // Label；目录树用缩进、折叠箭头和文件夹图标代替 ├─ └─，序号不常显（悬停提示里写 ⌘1–9）；进度用细进度条代替字符块。
  • 选中与悬停：圆角高亮（侧栏是灰底，图标栏的图标取强调色），代替粉色竖线和反色。
  • 颜色：系统的语义色（窗口、侧栏、分隔线、次要文字），深浅跟随系统；强调色见待定 1。
  • 动效：系统的淡入淡出。不放 glitch、扫描线刷新、文字标显形和运行中的闪动。
  • 不随外观变的：布局与入口（图标栏、顶栏、状态栏、手机的三个标签页）、快捷键、终端屏幕里的内容与配色（仍取 iTerm 的）、浏览器里的网页、确认与安全提示的内容和步骤。
