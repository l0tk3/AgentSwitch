叠窗：应用图标与应用标记

三个叠着的终端窗口，最前面那个停在提示符上等你输入。应用图标有经典版（液态玻璃）和像素版；应用标记是同一幅图的小号，最前面那个窗口的标题栏就是状态灯。“一分三”那张图不再是应用标记，只留作 Dispatch 页的图标。规范见 docs/ui-v0.md §10。

// APP ICON

经典版是一份分层文件（AppIcon.icon）：黑色渐变的底、三块由远到近越来越实的玻璃、深色的提示符与光标，高光与半透明由系统渲染，这里只是平涂的示意。深色、透明、着色几种样式由系统按同一份文件给出。像素版（AppIconPixel.icon）逐格画，18 × 15 格，纯黑底，墨色六阶；三个窗口都是不带标题栏的面板，最前面一块上是五行的 > 和一行的光标；外观设置是 Pixel 时程序坞和主屏幕用它。两个图标都没有彩色。
