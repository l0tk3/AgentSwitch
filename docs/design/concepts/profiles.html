WHAT THIS PAGE IS

docs/profiles-v0.md 的原型：都还没做，是用来对样子和规则的。四个场景上面可以点；场景里凡是看起来能点的也能点（切换当前配置、新建、右下角的浏览器图标、结束一轮、把标签留下）。

THE RULES IT SHOWS

  • 配置属于一个 agent，各管各的；行首的单选就是“当前配置”，换了之后新开的终端用它，开着的不动。
  • 没指定指纹和代理的配置用 This Mac（真实指纹、不走代理、现在那个浏览器）；指定了的有自己的浏览器，只属于这一个配置，不和别的配置、别的 agent 共用。
  • 右下角的浏览器图标在状态栏最右端（原来锁的位置），点一下把这个终端所用的浏览器叫到前面；机器上不止一个浏览器时旁边写明是哪个。
  • 标签页按 Codex 客户端的办法管：每个终端只管自己开的；agent 开的标签这一轮结束就关，除非标了 Kept（给你的结果）或 Handoff（等你操作，下一轮接着做）；你接手过的也留下。
  • 配置有颜色（Default 没有）：Agents 页里名字前的圆点；在它名下运行着的终端，列表行尾和状态栏里带一颗同色的亮点。颜色说的是“谁”，不是状态——都避开状态色，位置和样子也和状态标记不同（已做，profiles-v0 §3.2）。
  • 没登录的配置，开终端就从登录开始（已做，§3.1）。
  • 登录走配套的浏览器：这个终端里要打开的网页都落到它自己的浏览器里，不碰你的默认浏览器。
