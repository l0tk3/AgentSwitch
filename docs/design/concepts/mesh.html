Mesh · 网状连接（演示）

每台 Mac 本来就是服务端（远程接口、配对码、钉证书指纹、设备令牌、Bonjour），网状 = 每台 Mac 也能当客户端：手机同时连多台 Mac，Mac 之间互相使用对方的 Dispatch 与 Terminals。只做“使用对方”，不做“跨机调度”（一台的调度模型把任务派到另一台：密文绑在各自网关的公钥上，另一台解不开）。静态演示，不连服务；上面的开关是还没定的几件事。
