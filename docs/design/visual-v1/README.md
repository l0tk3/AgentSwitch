# 视觉语言 v1 的演示页

`docs/ui-v0.md` §7 的活样本：直接用浏览器打开（file:// 即可，不连服务，数据是写死的）。改规范时同步改这里；写新界面时先对照这里的样子。

- `app.html`：规则、深浅两套颜色、标记与抖动、字、以及 Mac 菜单栏下拉与 iPhone（tasks 深色、terminals 浅色）的样子。
- `terminal.html`：终端窗口——目录树侧栏（同一父目录合并）、新建面板（文字标显形、agent 像素图、模型、单选权限）、权限请求、加密发送、切换终端；顶部可切 English / 正式中文两套短词（已定 English）。
- `phone.html`：iPhone 的终端——列表（折叠、逐行画出、长按菜单、删除擦除）、新建（文字标显形、选 agent 的 glitch、bypass 确认）、终端页（打开时刷新、拖动发滚轮、权限卡、加密框围住同一个输入框、`/` 补全、像密码时先问）；底部是和桌面对照的特效清单。
- `depth.html`：像素的层次——硬阴影、台阶补半亮（次像素抗锯齿）、挤出、LCD 次像素，各自用在哪、不用在哪。
- `pixel.js`：这几页共用的像素库（标记、agent 图、文字标、glitch）。产品里的正式版本是 `packages/daemon/ui/pixel.js`（ES module）；两边的图形数据保持一致。
