菜单栏实时活动 · Mac

照 macOS 26 把 iPhone 实时活动放进菜单栏的样子：菜单栏里一个小胶囊，点开是和手机锁屏同一张卡。有请求时卡片自己落下，在卡上批准或拒绝；任务结束、终端的一轮做完或出错时落下几秒显示结论并响一声；失败的结果一直留着（胶囊红色），直到你点开看过。

壁纸 大小
// live · 动态

点胶囊展开或收起，双击打开；点别处收起。演示里完成的结果 10 秒后消失（应用里 1 分钟）；失败的留到你点开卡片看过、或打开了那个任务 / 终端，几条失败按新到旧列在卡上。终端窗口正显示那个终端时，它的结果不提示。

// menu bar · 菜单栏

只在有任务或请求时出现，在 AgentSwitch 图标左边。胶囊不动，只有计时在走。

// card · 卡片

能用按钮答的在卡上答；要打字的点 [ open ]，打开任务页。点标题打开终端窗口或任务页。

// other · 其他
  • 不抢焦点：在卡上点 allow，当前窗口不会被切走。
  • 等你时响一声，和手机同一个提示音。
  • 全屏应用里菜单栏藏起来，请求的卡片照样落下。
  • 设置 › 通用 可关。AgentSwitch 自己的菜单栏图标不变。
