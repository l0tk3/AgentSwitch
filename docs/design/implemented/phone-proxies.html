iPhone 上管理代理的几页（已做，2026-10-09）。能点：Clash 页里点一行换节点、开关规则模版，Nodes 页里勾选节点。

WHAT THIS PAGE IS

手机上的代理：Settings › Proxies 一段三类行——Clash、共用的 Browser、每个配置一行（带它的颜色）；右边写它现在的状态或出口。点进去是 Clash 页或代理表单。

THE RULES IT SHOWS

  • Clash 页和 Mac 上的是同一页：状态、订阅、给 Claude 和 OpenAI 的节点（点一行换用哪个；<x> 是现在用的）、规则模版与 DNS、直连地址、路由检查。少的只有“把 AgentSwitch 订阅加进 Clash Verge”这一步：那是在 Mac 的 Clash Verge 里点的。
  • 单选是 < > / <x>，多选是 [ ] / [x]（ui-v0 §7.2.6）；经典外观是圆环与方框。
  • 代理表单两处共用：共用浏览器的（Apply、Direct）和配置的（Apply & Check、No Proxy、Check Exit）。整条 http://用户名:密码@主机:端口 粘进 Server 会自己拆开。
  • 密码不以明文离开手机：在手机上用 Mac 网关的公钥封成密文，只对代理自己的 host:port 有效；已存的密码显示 Kept，不回传。
  • 留在 Mac 的：新建、删除配置，登录，配置的颜色，浏览器的指纹（手机上只看得到一行摘要）。
  • 旧一些的 Mac 不给这些接口：这一段里没有的行就不出现，全没有时整段不出现。
