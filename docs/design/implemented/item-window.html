// RULES

  • 主窗口只有一个；单独的窗口只放一样东西，换不成别的。先是一个终端，Browser 的标签页和 Dispatch 的任务页随后用同一种窗口。
  • 入口：列表里右键 Open in New Window，顶栏标题右键也有。收回：右键 Move Back Here，或者关掉窗口后在列表里点它。
  • 一样东西只在一处：开出去以后主窗口里那一块空出来；点列表里那一行（或 ⌘1–9、实时活动的卡片）是把它的窗口带到前面。
  • 关窗口不结束终端：⌘W 只关窗口。在列表里 Close 掉终端，它的窗口跟着关。
  • 状态栏：左边是终端的名字（这里没有列表），右边同主窗口。网关和手机在线留在主窗口。
  • 快捷键：⌘↩ / ⌘⌫ 答确认卡，⌘⇧V 加密发送，⌘W 关窗口，⌘T 回主窗口新建终端。
