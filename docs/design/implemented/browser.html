Browser · 浏览器（演示）

Mac 上一个由服务持有的浏览器（同终端）：App 是它的屏幕，手机和 Mac 都能看、能点、能打字；Codex、Claude Code、OpenCode 经凭据网关的浏览器工具操作的是同一个——你看到的就是它正在操作的那一页，随时接手、交还。登录态共用，密码用密文填。你在 App 里还能打开 Mac 上的本地网页和 localhost，手机拿到的只是画面。静态演示，不连服务。

页面缩放（2026-10-03，用户：然后我发现agentswitch的浏览器页没有放大缩小的选项，加上 用来调节大小；browser-v0 §1 页面缩放）：浏览器自己的缩放，同 Chrome——页面按更小或更大的窗口重新排版，画出来就更大或更小。Mac 在状态栏最右边，手机在底栏键盘键之后；只有设尺寸的那块屏幕能调，比例按站点记在各自的设备上。下面两端都可以直接调，每块屏幕下方的一行写出这块屏幕设给服务的尺寸。

IPHONE
Browser 标签页：按持有者分组——你开的、终端里的 agent、调度的任务；agent 正在操作的转圈，等你的琥珀。右上 + 开新标签：网址、Mac 上的路径或 localhost；底下列出 Mac 上正在监听的本地服务。
MAC · MAIN WINDOW, THIRD PAGE
主窗口多出第三页 Browser（Dispatch · Terminals · Browser，⌘0 / ⌃⇥ 之外加 ⌘⇧B），左栏标签列表同手机，右边是画面，键盘鼠标直接转发。点左栏切换标签；Codex 的标签上标出它刚操作的元素。待定：也可以不画画面，而是一个真正的 Chrome 窗口。
左栏同终端页的侧栏（2026-10-03）：拖右边的点线改宽窄（220–560，给画面留 420；双击复原 290），拖过最左边松手即收起、不留细栏；顶栏页面切换后的侧栏按钮或 ⌘B 开关，宽度与开关记在本机。你的标签显示在 Mac 上时归这台 Mac：换成画面区域的尺寸，画面按显示器的像素来，一个 CSS 像素画成一个点。
状态栏与页面缩放（2026-10-03）：页面底部原来的那一条在横跨整个窗口的状态栏右边（样子见 window-bars.html）。最右边是 − 100% +，位置不随前面的内容变：− 与 + 各换一档，点百分比回到 100%（不是 100% 时用正文色）；指针在这个窗口上时 ⌘+、⌘− 同样有效。只有这台 Mac 在设尺寸的标签能调——你的标签，或 [ Take Over ] 之后 agent 的标签；未接手时三个都暗着，悬停说明原因。比例按站点记：两个 github.com 的标签共用一个比例，localhost:5173 另记。可用的档位随画面区域而定，拖动或收起左栏后随之改变。
WHAT CODEX SEES — 同一个标签
← Codex 在终端里（或调度的任务里）调用的浏览器工具，经凭据网关、连到宿主里它自己的标签：就是上面手机和 Mac 正在显示的那一页。

它看到的是脱敏后的页面快照，截图里密码框和受保护的值被遮住；密文只按允许的站点填入。你接手时它的调用排队等待；交还后接着做。

浏览器没有调试端口，Codex 的 shell 连不到它，只能经这个工具。
