// RULES

  • 一个标签一个窗口：从 AgentSwitch、手机或 agent 打开的标签各是一个 Camoufox 窗口；你在 Camoufox 里用 ⌘T 开的仍是同一窗口里的标签。agent 打开窗口不抢键盘焦点。
  • 接手：服务在页面里放一个页面自身读不到的监听，发现不是 agent 发出的输入即视为你接手：agent 的操作排队，接手期间的网络与控制台记录不交给它。密码请在自己的标签里输入，或让 agent 使用 secret_fill。
  • 手机：仍是画面。接手时 Mac 上的窗口缩到手机宽度（不低于 500 点），页面是窄窗口里的桌面版，不再模拟手机。
  • 身份：指纹保存在配置里、保持不变；更换需重新启动浏览器。代理经服务自己的转发层，更换即时生效；对本机被禁端口与 file: 的拦截也在这一层。
  • 引擎：Camoufox 与 Playwright 成对更新（GET /browser/engine、POST /browser/engine/update，设置的环境检测页与命令行同此）。下载、核对校验值、自检、切换、删除旧版本；压缩包解包后即删，中断的更新在下次启动时清除；不使用 Playwright 自己的浏览器缓存目录。Playwright 装在应用包之外，自检未通过时退回包内的版本。
