# 界面设计规则（写界面前必读，写完逐条核对）

用户（2026-11-26，#451）：每次写新功能的界面都会有一些设计不规范的地方，要一份严格的设计规范，开发时自动遵守。

这一页是规则本身，短而硬。来历和细节在 `docs/ui-v0.md`（§7 像素外观、§8 与 §8.1 经典外观）。两处不一致时改这一页并说明原因，不要悄悄绕开。Mac 的测试 `DesignRulesTests` 会查其中能自动查的几条。

## 0. 流程

1. 动手前读这一页；新页面先找一个现有的同类页面照着写（列表页照 Channels，表单页照 Settings › Redaction，独立窗口照 Passwords）。
2. 两种外观都要画：`look.isClassic` 的两支都写，不能只写一支。像素外观的现有画面不许因为新功能而变。
3. 写完用 `-designPreview` 出图，像素、经典深色、经典浅色各看一遍；没看过的要在汇报里说明。
4. 给用户看界面：真实页面的渲染图放本地网页，在共享浏览器里打开。

## 1. 颜色

1. 只用现成的颜色名：`Look.ground / ink / ink2 / faint / line / panel / raised / hover / said / sidebar / ring`，`Color.signal / waiting / ok / failed / busy`。**不许在页面里写新的颜色数值。** 需要新颜色，先加到 `Look`，并在 `ui-v0.md` 记一行。
2. 强调色只用于：主操作按钮、选中、链接、输入焦点。状态色只表状态：绿 = 正常 / 空闲，琥珀 = 等你处理，红 = 失败 / 危险。颜色不用于装饰。
3. 每个颜色都要有深色和浅色两个值；终端页总是暗色。

## 2. 层次（经典外观，§8.1）

1. 窗口的底 = 内容的底。标题栏、图标栏、状态栏画在底上，没有自己的底色。
2. 侧栏（列表、成员、Files）是浮起的卡片：用 `sideCard()`，不要自己拼背景、圆角和阴影。
3. 内容里的块（卡片、输入框、代码、提示）用 `Look.panel` 或 `Look.raised` 加圆角。一个块里不再套有底色的块。
4. 不画横贯内容的分隔线。表单卡片内部的行间细线可以有。

## 3. 形

1. 圆角只用这几个：`Look.controlRadius`（8，控件、列表行）、`Look.cardRadius`（12，卡片、浮层、侧栏）、`Look.bubbleRadius`（16，气泡、输入框）。**不写别的数字。** 像素外观一律直角。
2. 间距只用 4 · 8 · 12 · 16 · 24。卡片内边距 12；侧栏与内容相隔 8（`Look.panelGap`）。
3. 列表行：高度一致；选中是整行圆角的强调色淡底，悬停是 `Look.hover`。
4. 用现成的零件：`BracketLabel` + `BracketButtonStyle`（按钮）、`SectionLabel` / `PartLabel`（小标题）、`StatusMark`（状态）、`BrailleSpinner`（进行中）、`LookGlyph`（图标）、`framed()` / `grounded()`（框与底）。它们自己按外观画。

## 4. 字

1. 界面文字用 `.mono(size)`（像素外观等宽，经典外观系统字体）或系统字体；等宽只给终端、代码、命令、路径。
2. 字号：标题 13–14 半粗，正文 12.5–13，辅助 11–12；不小于 10.5。对话里的字号经 `Look.size` / `Look.prose` 取，跟随 `Text Size` 设置。
3. 层级靠字重和颜色（`ink` / `ink2` / `faint`），不靠更多的框。

## 5. 文案

1. 短词（按钮、标签、标题、状态、占位提示）用英文，按苹果的标题式大写：`New Channel`、`Replace Only`。整句用书面中文。不要中英文短词混着来。
2. **不加小字说明**：控件下面的灰色解释、分组脚注、弹窗开头的介绍段都不要。只保留报告状态或问题的文字（已关闭、出错、对刚输入内容的警告）。解释写进文档。
3. 不拟人：不说“我”“在想”“收到啦”。状态用名词或短动词。
4. 一个图标一个意思；别处用过的图标不拿来表示新的东西。经典外观的图标用 SF Symbols（新的像素图要在 `PixelArt.symbols` 里配上对应的符号）。

## 6. 行为

1. 不改现有功能的位置、入口和快捷键，除非用户要求。
2. 凭据类功能以好用为先；能脱敏就不要拒绝；提醒只说一次。
3. 新窗口照 `SettingsWindowController` / `PasswordsWindowController` 的做法：能缩放、记住位置、⌘W 关闭、编辑快捷键可用。
4. 会动的东西在看不见时停（`\.onScreen`）；经典外观不放扫描线、闪动和 glitch。

## 7. 汇报

说清楚：做了什么、看过哪些图（哪种外观、深浅）、没看过什么、有没有打包。不要把没验证的说成做好了。
