# ui-v0：Mac 与 iPhone 应用的界面规范

2026-09-25 用户要求：用统一的审美重做两个应用的前端，并去掉“助理在想”这类 AI 味重的描述。本文是两端共同的准绳；改界面先看这里。

## 1. 原则

1. **安静的工具，不是聊天机器人。** 内容第一，外框最少。界面不拟人：不说“我”“在想”“收到啦”，状态用名词或短动词。
2. **一个主色，状态色只表状态。** 其余都是灰阶。颜色不用来装饰。
3. **层级靠字重、字号和留白，不靠框。** 每一项最多一层容器（一张卡片）；不在卡片里再套彩色块。
4. **一眼看状态，细节点进去看。** 状态 = 小圆点 + 一个词；长文、事件流、技术细节放在详情页。
5. **技术名词说人话。** 模型用人名（Opus 5.5、Sonnet 4.6、DeepSeek Flash、GPT-6 Luna），执行器只在需要时出现（Claude Code、Codex、OpenCode），路径缩短（`~/Projects/AgentSwitch`）。

## 2. 颜色

| 用途 | 浅色 | 深色 | 说明 |
|---|---|---|---|
| 主色（按钮、选中、进行中、链接） | `#2F5BEA` | `#6D8BFF` | 两端的 AccentColor |
| 主色填充（自己的消息、发送按钮等白字底） | `#2F5BEA` | `#3F66F0` | 深色模式下比主色深，白字才清楚 |
| 等你处理 | `#E8891C` | `#F5A54A` | 只用于需要用户动手的东西 |
| 完成 / 正常 | 系统绿 | 系统绿 | 任务的结束状态；Mac 菜单与环境页里服务、网关、网络“运行正常”的状态点 |
| 失败 / 删除 | 系统红 | 系统红 | 只在出错、危险操作出现 |
| 文字 | `.primary` / `.secondary` / `.tertiary` | 同 | 三档，不自定义灰 |
| 表面 | iOS：对话页用 `systemBackground`，卡片 `secondarySystemBackground`；设置类页面用 grouped 背景。Mac：窗口背景 + 分组表单 | 同 | 不用半透明叠在内容上 |

## 3. 字与间距

- 字：iOS 正文 `.body`，次要 `.subheadline`，辅助 `.footnote`，元信息 `.caption`（`.secondary`）；数字用等宽数字。Mac 正文 `.body`，分组标题 `.headline`，说明 `.callout`/`.caption` 次要色。
- 间距刻度：4 · 8 · 12 · 16 · 24。卡片内边距 14（iOS）/ 12（Mac）；时间线条目之间 20。
- 圆角：卡片 14，气泡 18，标签用胶囊。
- 图标：SF Symbols，单色，跟随文字颜色；只有状态点带状态色。设置里的行要么都有图标，要么都没有。

## 4. 文案

- **不拟人**：不写“助理在想”“我来帮你”“好的呢”“收到啦”。等待中写“发送中”“处理中”。
- **状态词**固定：排队 · 进行中 · 等你处理 · 已完成 · 未完成 · 失败 · 已取消。
- **占位与空状态**：输入框“输入任务或问题”；空状态一句话 + 两三个例子。
- **按钮**：动词开头，两到四个字：发送、重发、修改、处理、删除、安装。
- **说明文字**：一句话以内，放在分组下方；更长的解释不放在设置页上。
- **时间**：刚刚、3 分钟前、今天 14:20。
- **用词**：daemon 叫“服务”，secret-gate 叫“凭据网关”，路由器模型叫“调度模型”（“调度”），harness 叫“执行器”（只在 Mac 设置和模型菜单里出现），thread 叫“会话”，任务日志叫“任务记录”。界面上不出现“助理”“路由器”“执行者”“守护进程”“分诊”“口播”。
- 对话里 AgentSwitch 自己的消息（回复、通知）是**陈述句**：“已交给 Opus 5.5。”“「财务平台登录」等你回答：短信验证码是多少？”——不寒暄，不用感叹号和表情。

### 4.1 语气：书面、克制、准确（2026-09-27）

用户反馈：“没等它”“排在前面的地址先连上了”这类说法太随便。去掉 AI 味不等于写成聊天口吻；界面文字按系统设置的写法来。

- **状态用词组，不用句子**：可用 · 0.1 秒、未使用、超时、已连接（局域网）、无响应。
- **说明用中性的完整陈述句**。不用口语词：句尾的“了”改“已…”；“没 / 没有”改“未 / 无”；“能 / 不能”改“可 / 无法”；不用“就、先、别的、一下、挺、吧、呢、啦、搞、弄”；不用比喻和拟人（“睡着了”“挤掉”“不认”“拿不准”）。
- **不用“它”指代程序、线路、模型**：写出主语，或者省略。
- **原因和操作分开**：先写原因（陈述），再写操作（动词开头）。“Mac 处于睡眠状态，或 AgentSwitch 未运行。”
- **“你”只用在需要用户动手的地方**（等你处理、请在 Mac 上修改），不用“您”。
- **不改的**：用户自己说的话（示例数据里的用户消息、任务原文）；模型生成的结果原文。

| 原来 | 改为 |
|---|---|
| 没等它 | 未使用 |
| 排在前面的地址先连上了 | 已通过优先级更高的地址连接 |
| 能连上 | 可用 |
| 每个地址同时试，排在前面的能用就用它。 | 同时探测所有地址，按顺序选用第一个可用地址。 |
| 连不上时手机会一直自动重试，不用一直开着这页。 | 连接中断时会自动重试，无需停留在此页面。 |
| Mac 睡着了，或者 Mac 上的 AgentSwitch 没在运行。 | Mac 处于睡眠状态，或 AgentSwitch 未运行。 |
| iPhone 上开着别的 VPN 应用，把 Tailscale 挤掉了 | 其他 VPN 应用正在使用 VPN 通道，Tailscale 未连接（iOS 同一时间只允许一个 VPN）。 |
| Mac 不认这台 iPhone 了，需要重新配对 | 配对已失效，请重新配对。 |
| 调度模型拿不准、它选的都用不了、或它自己出错时，任务交给这个。 | 调度模型无法判断、所选模型均不可用或调度出错时，任务交由此模型执行。 |
| 手机丢了就在这里吊销，它会立即断开。 | 设备丢失时可在此吊销，吊销后立即断开连接。 |
| 可以开始了 | 引导完成 |

### 4.2 用量（2026-09-27）

用户要求：用量不要藏在“模型与额度”里；Claude 的 5 小时和 7 天窗口都要显示，用小进度条。

- **数据**：`GET /quota` 的 `detail.windows`（`[{label, usedPercent, resetsAt}]`，Claude Code 与 Codex 都有）和 `detail.balances`（DeepSeek 余额，OpenCode 用）。
- **一行一个执行器**：左边单色图标块 + 名称（Codex 带套餐，如 Pro），下面两个固定槽位 `5h ▬▬▬ 20%` `7d ▬▬▬ 82%`；没有读数的槽位画空条、写“—”。OpenCode 这一行写“余额 ¥96.23”，不画条。
- **条的颜色**：系统绿；用到 90% 及以上用系统红。重置时间已过的窗口视为已重置，显示“—”。
- **位置**：iPhone 在设置首页 Mac 信息下面，单独一组「用量」，下拉刷新会强制重读；Mac 在菜单栏面板的状态行下面，以及「模型」页顶部。
- **图标**（两端一致，SF Symbols 单色）：Claude Code `terminal`，Codex `curlybraces`，OpenCode `chevron.left.forwardslash.chevron.right`。

## 5. 两端的调试预览

- iPhone：调试版 `-uiDemo YES [-uiDemoScreen settings|task|done|running|stale|interrupted|onboarding|mac|offline|offlinemac|tasks|search|sessions|transcript] [-uiDemoOpenTools YES] [-uiDemoScroll route]` 用示例数据打开，不连 Mac；模拟器截图看效果（`-uiDemoOpenTools` 把任务页的工具调用全部展开；`-uiDemoScroll route` 把 Mac 详情页滚到「上次选择线路」，模拟器截图没法手动滚动）。
- Mac：调试版 `-designPreview <dir>` 用示例数据把菜单栏面板和每个设置页画成 PNG 后退出，不起服务、不碰正在运行的实例。

## 6. 落地（2026-09-25）

- iPhone：首页（对话、进行中条、任务卡片内嵌提问）、任务页（请求 · 状态行 · 摘要 · 结果 · 文件 · 过程）、设置（Mac 状态头 + 无图标分组行，连接细节进子页）、首次配对页；`Theme`（`App/Sources/Design/Theme.swift`）集中间距、圆角、状态色和 `StatusLabel`、`.card()`；`ModelName`（Kit）把模型 id 说成人名。“等你回答”的通知在问题未答时不进对话（卡片里已有），答完留作记录。
- Mac：设置窗口改侧边栏 + 分组表单，标题与操作在工具栏；菜单栏面板 = 标题行（一句状态）+ 四个状态点行 + 待处理 + 新版本 + 操作行；原菜单里的端口、pid、地址移到「环境 › 服务与网络」。`DisplayText`（Core）负责模型名、执行器名、`~` 路径、相对时间和状态短词。
- daemon：助理的固定回复与主动汇报改成陈述句（“已建任务。”“「标题」已完成：…”“「标题」等你回答：…”），汇报里的模型名用人名（`util/modelName.ts`），等你处理的汇报用独立 kind `waiting`；登记簿给调度模型的状态词与界面一致。网页控制台未改。
- 工具调用（2026-09-25）：任务页「过程」里每次调用一行（动词 + 对象：“运行 git log …”“读取 src/x.ts”“浏览器 · 打开 …”“填入密文”），点开看输入（逐字段）和结果。daemon 的 `tool_call` 带 `id`、`input`（`executors/toolEvents.ts` 截断），结果是同 `id` 的 `tool_result {ok, output}`（Claude、Codex；OpenCode 在 `tool_call` 里直接带 `output`），输出截到 1500 字。Claude 的输出只含它本来看得到的东西（禁区读不了，网页经 gate 遮罩）。
