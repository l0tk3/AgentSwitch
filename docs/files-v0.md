## 0. 要点

- **`Files`：主窗口自己的一栏，在右边。** 它属于窗口，不属于哪个终端：换终端、换页、分屏、合屏它都还在，显示的是同一个位置。默认关着（用户定）。两种放法（§2.1）：**靠边**，页面让出宽度；**浮起**，浮在页面右边，页面不变窄、终端的列数不变——`⋯` › `Float Over Page` 换，记住。宽度可拖（默认 300 点，240–560）。开没开、放法、宽度、位置、展开了哪些文件夹，按节点各记各的。
- **两种外观各有自己的默认看法**：像素外观是**目录树**（`tree` 命令那种 `├─ └─ │` 字符画，等宽，一棵树里一层层展开）；经典外观是**文件夹**（Finder / iOS“文件”那种：一次一层，文件夹图标加 `›`，点进去换一层，`‹ ›` 前进后退），栏拉宽到 460 点以上变成 Finder 的**分栏**（用户定，§3.3）。`⋯` 菜单里两种看法都能换（`As Tree` / `As Folders`），记在这一台设备上。
- **绝对路径，每一层可点**：栏顶一行是当前文件夹的完整路径（`/ Users / you / Projects / lumen /`），点哪一层就到哪一层；太长时中间收成 `…`，点开是被收起的那几层。
- **入口**：
  - 左边列表里文件夹、终端、会话的右键菜单多一项 `Show in Files`：到那个文件夹（终端是它此刻所在的文件夹）。
  - 顶栏右边一个文件夹图标：到焦点那一块的文件夹；分屏时每块的标题栏上也有一个，到那一块的——和现在顶栏与标题栏上的终端 / 简略切换同一个排法。图标亮着表示文件栏正显示这一块的文件夹，再点一下收起。
  - 第一次打开在家目录，之后回到上次的位置。快捷键 `⌘⇧F`（同顶栏的图标；用户定）。
- **选中给 agent**：选一个或几个（⌘ 点、⇧ 点），`Add to Reply`、或拖到某一块上——落进那一块的回复框，是光标处的 `[File #n]` 占位符，和今天拖文件、`+` › `Files…` 是同一条路（发送时输入路径，文件不拷贝）；终端视图里拖上去照旧是输入路径。文件夹给的也是路径。**可能含凭据的文件**（`~/.ssh/`、`.env`、各 agent 的登录文件……）照常能看、能预览，给 agent 时先问一句（用户定，§4）。
- **预览**：Mac 上选中一个文件，栏的下半是它的预览（文字、代码、图片、PDF 都由系统的 Quick Look 画；`空格` 放大成 Quick Look 的面板）；`⋯` › `Show Preview` 可以关掉，只留空格（用户定：可以设置）。预览下面只有两个按钮 `Add to Reply` `Open`，其余都在右键菜单里。手机上点一个文件推进一页：文字由应用自己显示前 64 KB（长行按页宽自动换行，行号只标在每行的第一排；用户 2026-10-19：压缩过的大文件只有一行，横着排不好看），图片、PDF 和其他交给系统的 `QLPreviewController`（先下载，上限 25 MB）。
- **手机**：第五个标签 `Files`（用户定），排在 `Terminals` 后面；终端页 `+` 菜单的 `Files on Mac` 留着，从那里选的直接落进那个终端。
- **只读**（第一版）：列目录、看信息、预览、给 agent、`Show in Finder`、`Copy Path`、`New Terminal Here`。不新建、不改名、不删除——这些在 Finder 里做（§9）。第三稿（§12，待定）提议加上新建、改名、移到废纸篓，手机上能存到手机、从会话页去它的文件夹。
- **服务给数据**：列目录、取信息、取预览都经服务的接口（`/files…`，§7），所以手机和别的节点用的是同一份；AgentSwitch 自己存凭据的地方（与 `protected.ts` 同一张表）列出来只有名字和锁，不能打开、预览、给 agent。手机和别的节点读这台 Mac 的文件，由这台 Mac 自己的开关管，并且每个配过对的设备各有一个**授权范围**（用户定，§7.5）。

|---|---|---|
| Apple HIG · Path controls | 显示所选文件或文件夹的路径；标准样式是“磁盘、上层文件夹、所选项”一串，每项带图标和名字，放不下时**隐去首尾之间的名字**；放在窗口内容里，不放工具栏或状态栏（Finder 的路径栏在窗口内容的底部） | 路径行放在文件栏内容的顶上（不进顶栏、状态栏）；经典外观照标准样式画（图标 + 名字 + `›`）；放不下时首尾留着、中间收成 `…` 菜单 |
| Apple HIG · Outline views | 层级数据放在一列；文件夹点三角只展开它自己，⌥ 点展开全部子文件夹；**记住用户展开到哪一层**；长名字用中间省略号；可以排序、可以有搜索框 | 像素的树：`▸ ▾` 只展开 / 收起，⌥ 点展开全部；展开状态按节点记住；名字中间省略（`very-long-…-name.ts`） |

## 2. 位置与层级（Mac）

- **一栏，在窗口右边，在顶栏与状态栏之间。** 顶栏和状态栏仍横跨整个窗口（dispatch-v0 §1、`bars.html` C）；左边是图标栏和页面自己的列表，中间是页面，右边是文件栏。靠边时文件栏和页面之间一条 1 点实线，可拖。按 `bars.html` 的规矩：有文件栏时这条线和顶栏、状态栏的线一起画完整，收起时不留线。
- **它是窗口的，不是页面的**：四页（Dispatch、Terminals、Browser、Clash）换来换去它都在；只有“给 agent”要看当前页有没有回复框（§4）。单独开出去的终端窗口（`item-window.html`）没有文件栏；那里的 `Show in Files` 把主窗口带到前面再打开。
- **和记录的右侧栏（`RecordSidePane`）**：那一栏在一块的里面、只说这个会话（上下文、任务清单、改过的文件）；文件栏在所有块的外面。两个可以同时开；文件栏靠边时块变窄，块不够 980 点时记录的右侧栏照它自己的规矩不出（simple-view-v0 §5.2）；浮起时块不变窄，记录的右侧栏照旧，被文件栏盖在下面。
- **记什么**：开没开、放法（靠边 / 浮起）、宽度、看法（树 / 文件夹）、显示隐藏文件与否、显示预览与否、排序、每个位置展开过的文件夹、最近去过的位置，按节点分开记在应用偏好里（同 mesh-v0 §9“每个节点记住自己的终端布局”）。

### 2.1 两种放法：靠边、浮起

用户（看过第一稿）：窗口窄时那个情况很好看 应该做成随时可以那样打开。

- **靠边**（默认）：一栏，页面让出它的宽度。
- **浮起**：浮在页面右边，从顶栏下沿到状态栏上沿；像素是 1 点墨色框加抖动的硬阴影，经典是左边两个圆角加投影。页面不变窄，所以**终端的列数不变**——靠边打开、收起会让右边那一块改列数，agent 的界面整个重画一遍，浮起没有这件事。适合“打开、挑几个文件、收起”。
  - 点页面不收起：焦点回到那一块，文件栏还在上面，可以接着往块上拖、接着在回复框里打字。收起用 `×`、顶栏或标题栏的图标、`⌘⇧F`，或者焦点在栏里时按 `esc`（焦点在终端里时 `esc` 照旧给终端）。
  - 盖住的是页面右边一截：最右那一块的回复框尾巴、记录的右侧栏在它下面。回复照样用 `↩` 发；要看被盖住的，拖窄或收起。
  - 宽度照样从左边缘拖，240–560 点。
- **怎么换**：`⋯` › `Float Over Page`（勾上是浮起），`View` 菜单里同一项；记住，下次打开还是这样。
- **窗口窄时**：靠边会让页面不足 520 点的时候，靠边的文件栏临时浮起；窗口拉宽后回到一栏。

## 3. 文件栏里有什么

从上到下：标题行、路径行、列表、底部（没选中时一行计数；选中了是预览，或者关了预览时是一行）。

### 3.1 标题行

- 左：`// Files`（像素）/ `Files`（经典）；窗口在别的节点上时后面跟 `@ Mac mini`（信号色，同顶栏）。
- 右三个按钮：`⌂` 回家目录（`⌘⇧H`）；`⋯` 菜单；`×` 收起（`×` 只表示关闭，ui-v0 §7.2 第 4 条）。
- `⋯` 菜单：`As Tree` / `As Folders`；`Show Hidden Files ⌘⇧.`、`Show Preview`、`Float Over Page`；`Sort By ›` 名字 / 修改时间 / 大小 / 类型；`Home ⌘⇧H`、`Go to Folder… ⌘⇧G`、`Places ›`。
- `Places`：家目录、各个终端此刻所在的文件夹（左边列表里有的）、最近去过的五个。左边列表本身就是项目的入口，这里只补“跳过去”的近路，不做第二套收藏。

### 3.2 路径行

- 当前文件夹的绝对路径，从 `/` 开始，每一层是一个按钮；最后一层（当前）墨色，前面的次一档。像素：`/ Users / you / Projects / lumen /`，等宽，悬停反色；经典：照 Path control 的标准样式，每层是文件夹图标加名字，层与层之间 `›`，悬停圆角底；最左的磁盘（`/`）只画图标，悬停写 `Macintosh HD`，左边 `‹ ›` 后退前进。
- 点一层：那一层成为当前文件夹（树以它为根 / 文件夹看法换到那一层）。右键一层：`Copy Path`、`Show in Finder`、`New Terminal Here`。
- 放不下时：首（`/`）尾（当前和它的上一层）留着，中间收成 `…`，点开是一串被收起的层（Path control 的做法）。
- 家目录写全路径（`/Users/you`），不缩成 `~`：用户要的是“绝对目录层级”。别处（列表、标题）照旧用 `~`（ui-v0 §1 第 5 条）。

### 3.3 列表

- **像素 · 树**（默认）：当前文件夹的内容，一行一项：树线、`▸ / ▾`（只有文件夹有）、名字（文件夹加 `/`）、右边淡色的大小与修改时间（`2.1K` `10/14` `Today 13:02`；栏宽不到 300 点时只留时间）。文件夹在前，各自按名字。点 `▸` 展开一层（⌥ 点展开全部子文件夹）；点名字选中；双击文件夹（或 `↩`）把它当作新的当前文件夹；双击文件是 `Open`（交给它的默认程序）。最上面一行 `../` 到上一层。栏拉宽也还是树，只是名字和右边的信息有了地方。
- **经典 · 文件夹**（默认）：一次一层，Finder 列表那种：类型图标（文件夹是强调色的线条文件夹）、名字、右边次要色的修改时间和大小；文件夹行尾一个 `›`。单击选中，双击或点 `›` 进去；路径行左边 `‹ ›` 后退前进（`⌘[` `⌘]`）。
- **经典 · 分栏**（栏宽 ≥ 460 点时的文件夹看法，用户定）：Finder 的分栏只留最后两栏，各占一半——左栏是上一层，当前文件夹在里面高亮着；右栏是当前文件夹。和 Finder 的分栏一样**单击文件夹就进去**：在右栏里点一个文件夹，整排往左移一栏，它的内容出现在右边；在左栏里点另一个文件夹，右栏换成它的。点文件是选中（预览照 §3.5）。`←` `→` 在两栏之间走，`‹ ›` 和路径行照旧。拖窄到 460 点以下回到一次一层。
- **几种看法共同的**：
  - 选中：像素是行左 3 点信号色竖条加浅一档的底（同左边列表）；经典是圆角的强调色底。多选 ⌘ 点、⇧ 点、`⌘A`。
  - 隐藏文件（`.` 开头）默认不列；`⋯` › `Show Hidden Files`（`⌘⇧.`，Finder 的键）。列出时与 `.git`、`node_modules` 一样淡一档。
  - AgentSwitch 自己存凭据的地方（§7.3）照列，名字后一把锁，淡一档；选不中、点不开、拖不走，悬停说明“此处存放 AgentSwitch 的凭据，无法在此打开。”。可能含凭据的文件（`.env`、`~/.ssh/` 里的）在列表里不另作标记，照常选、照常看，给 agent 时才说（§4）。
  - 符号链接：名字后 `→ 目标`（淡色）；进去或预览时按目标的实际位置判断能不能打开。
  - 一个文件夹超过 2000 项：先列 2000 项，末尾一行 `▸ 1,240 More`。
  - 读不了的文件夹（系统没给 AgentSwitch 访问权限，macOS 的“文件与文件夹”）：一行说明“AgentSwitch 无权访问此文件夹。可在“系统设置 › 隐私与安全性 › 文件与文件夹”中允许。”，`Open System Settings`。第一次读“桌面”“文稿”“下载”时系统会在 Mac 上问一次；从手机读时手机上写“Mac 上正在询问是否允许 AgentSwitch 访问此文件夹。”。
  - 文件变了：当前文件夹每 3 秒看一次修改时间（与终端列表同一个节奏），变了就重读这一层；没在看的不读。
- **右键一项**（系统菜单）：`Add to Reply`（`⌥↩`）、`Quick Look`（空格）、`Open`；`Show in Finder`、`Copy Path`（`⌥⌘C`，Finder 的键）、`Copy Relative Path`（相对于焦点那一块终端的文件夹；不在它下面时变灰）；文件夹另有 `New Terminal Here`。文件夹的 `Open` 是把它当作当前文件夹（同双击）。

### 3.4 键盘（焦点在列表里时）

- `↓ ↑` 移动；`→` 展开 / 到第一个子项，`←` 收起 / 到上一层（树）；经典看法里 `→` 等于进去、`←` 等于后退一层（`⌘↓` `⌘↑` 同 Finder），分栏时是在两栏之间走。
- `Home` `End`；打字跳到以它开头的下一项（APG typeahead）；`*` 展开同层全部（树）。
- `空格` Quick Look；`↩` 打开文件夹 / 文件（与 Finder 的“↩ 改名”不同：第一版没有改名）；`⌥↩` `Add to Reply`（不用 `⌘↩`：终端页的确认卡用它）。
- `⌘⇧F` 开关文件栏、`⌘⇧H` 家目录、`⌘⇧G` 去某个文件夹、`⌘⇧.` 隐藏文件（用户定：这一组照这一稿）。`esc`：靠边时回到页面（焦点还给那一块），浮起时收起。

### 3.5 预览（Mac）

用户（看过第一稿）：这个按钮排列太不文明了 把在访达打开改成在右键菜单里吧；预览的位置“改成可以设置”。

- **开着预览**（默认，`⋯` › `Show Preview` 勾着）：选中一个文件，列表下面分出预览（默认占栏高的 45%，中间的线可拖）：
  - 第一行：名字；第二行：`TypeScript · 2.1 KB · Today 13:02`（类型、大小、修改时间；文字文件加行数）。
  - 内容：文字（服务按类型判断的）一律用栏自己的等宽视图显示服务给的前 64 KB（像素外观带行号）——Quick Look 把 `.ts` 当成 MPEG-2 视频，只画图标（2026-10-16 做的时候看到的）；本机的图片直接从文件画；本机的其余（PDF、音视频、Office 文件）交给 `QLPreviewView`；别的节点上的图片显示服务做的缩略图，其余只写信息。

  - 选中一个文件夹：写它的项数与修改时间，同样两个按钮（`Open` 是进去）。
- **关了预览**（`Show Preview` 不勾）：列表占满；选中后底部只有一行——名字和大小（几个时是 `3 Items · 24 KB`），右边 `Add to Reply`。要看内容按空格。
- `空格`：Quick Look 的面板（`QLPreviewPanel`），和在 Finder 里按空格一样；方向键在面板里换上一个、下一个。开不开预览都一样。
- 预览只在用户选中时取；滚动列表不取。

## 4. 给 agent

- **落到哪**：焦点那一块的回复框（简略视图），是光标处的 `[File #n]` 占位符，回复框上面多一个带文件名的小条和 `×`——和今天拖文件进来、`+` › `Files…` 完全一样（simple-view-v0 §5.1“回复带文件”）：发送时服务在占位符处输入路径（空格和 shell 的特殊字符前加反斜杠），**文件不拷贝**；Claude Code 和 Codex 见到图片的路径就当图片附上。一次至多 10 个（同现在）。
- **三种做法**：`Add to Reply`（按钮、右键、`⌥↩`）；拖一项或几项到某一块上（落到那一块，不一定是焦点那块）；拖到回复框的某个位置（插在那里）。
- **终端视图**：那一块没有回复框；`Add to Reply` 和拖上去都是把路径打进终端的光标处（与从 Finder 拖进终端一样），不回车。
- **文件夹**：给的是它的路径，占位符也是 `[File #n]`（小条上是文件夹图标）。
- **Dispatch 页**：落进 Dispatch 的输入框，作为这条任务的附件（路径）。
- **Browser、Clash 页**：没有回复框，`Add to Reply` 变灰，悬停说明“此页没有回复框。”。
- **别的节点**：窗口在别的节点上时，文件栏列的是那个节点的文件，给那个节点上的 agent 的就是那边的路径——不用上传（今天别的节点的回复附件要上传，mesh-v0 §5.2）。
- **不能给的**：AgentSwitch 自己的禁区（§7.3）。选中里混着它们时按钮变灰并说明。
- **可能含凭据的文件**（用户定：敏感文件看就行，不过发送给agent的时候加上预警；哪些算，§7.3）：给之前问一次。
  - Mac：那一块回复框上方弹出一张卡——像素是琥珀色标题栏的方框加硬阴影，经典是圆角的卡——标题 `Add to Reply?`，说明“`.env` 可能含有密码或密钥。交给 agent 后，它能读到其中的内容，并可能发给模型的服务商。”（几个一起加时列出名字：“这 2 个文件可能含有密码或密钥：`.env`、`id_ed25519`。…”），`[ Cancel ]` `[ Add ]`。混着普通文件时，`Cancel` 只拿掉这几个，别的照加。
  - 加进去以后，它的小条上带琥珀色的 `!`（经典是三角），悬停写“可能含有密码或密钥。”。发送时不再问。
  - 终端视图里是同一张卡，`Add` 以后才把路径打进去。
  - 拖进来的（Finder 的、文件栏的）、`+` › `Files…` 选的、手机上加的、Dispatch 的附件，用同一张表、同样问一次。
  - 问的是“交给 agent”这一步。只是看、预览（手机上也是）不问。

## 6. 和别的设计的关系

- **terminal-v0 / simple-view-v0**：回复框的附件、占位符、发送时输入路径，原样用；新加的是“文件来自服务列出的路径”这一种来源（手机：`{path}` 附件），和“可能含凭据”的那一问（对所有来源）。
- **mesh-v0**：文件栏跟着窗口的节点走（顶栏的节点选择）；每个节点记自己的位置；`/files…` 进远程表；`Settings › Nodes` 多一个节点自己的开关和每个设备的授权范围（§7.5）。
- **profiles-v0**：与配置无关；文件栏读的是服务所在账户能读的东西。各配置自己的登录目录算“可能含凭据”（§7.3）。
- **ui-v0 §7 / §8**：像素用字符、树线、`▸ ▾`、`[ Add to Reply ]`；经典用系统字体、线条图标、圆角、强调色。演示页里两种都画了。

## 7. 服务

### 7.1 接口（草案）

已做（2026-10-16，daemon `src/files/browse.ts`、`src/api/browse.ts`）。错误一律 `{error: <码>}`：`bad-path`、`not-folder`、`folder` 400，`not-found` 404，`locked`、`scope`、`permission`、`files-off` 403，`too-large` 413。一层的列表带版本（`ETag`），没变时 304。`/files…` 都是 GET、只读，路径一律是绝对路径（`~` 由服务展开）；本机的应用经本地令牌，手机和别的节点经远程表，并受 §7.5 的开关与范围管。

| 接口 | 给什么 |
|---|---|
| `GET /files?path=<abs>&hidden=0\|1&limit=2000` | 一层：`{path, parent, home, entries: [{name, kind: dir\|file\|link\|other, size, mtime, hidden, dim?, locked?, link?: {target, kind}}], more, scoped?}`；不给 `path` 时是家目录（范围是 `Selected Folders` 时是第一个授权文件夹）；`scoped: true` 表示这一层只列了通往授权范围的项 |
| `GET /files/stat?path=<abs>` | 一项：同上的字段，加 `type`（`text` `image` `pdf` `audio` `video` `archive` `binary`，按扩展名和前 8 KB 判断：有 NUL 或不是 UTF-8 就不当文字）、文字的行数（读到 256 KB 为止）、文件夹的项数、`sensitive?: {reason}`（§7.3） |
| `GET /files/preview?path=<abs>` | 文字的前 64 KB（`{text, truncated, lines?, size}`，切在整字上）；不是文字回 415 `{error: "not-text", type}` |
| `GET /files/thumbnail?path=<abs>` | 图片的小图：Mac 上用系统的 `sips` 做（长边 512 像素，JPEG），做不了时 5 MB 以内的原图照给；不是图片回 415 |
| `GET /files/content?path=<abs>` | 原样的字节，支持 `Range`；超过上限（手机 25 MB）回 413。给手机的 Quick Look、别的节点上的文件的 Quick Look 用 |
| `GET` / `PUT /settings/mesh` | 多一个 `files: boolean`（`Paired Nodes May Read Files`）；只在本机 |
| `PUT /devices/:id/files` | 这个设备的范围 `{mode: home\|all\|folders\|none, folders?: [abs]}`（文件夹按真实位置存，须是在的文件夹）；`GET /devices` 每项带上它（`files`）；存在 `mesh.json`，设备吊销时删掉；只在本机 |

`/terminals/:id/input` 的 `attachments` 多一种 `{path}`：服务检查路径存在、不在禁区、在调用方的范围里，再按占位符输入这个路径（与 `{token, upload}` 搬进附件目录后输入路径，是同一个后半段）。“可能含凭据”的那一问在界面上做，服务不拦：用户确认过的照收。

### 7.2 本机的应用怎么用

- 列表、信息经服务（手机、别的节点、本机走同一份代码和同一张保护表）。
- 本机文件的预览：应用拿到路径后直接交给 Quick Look 画（应用和服务是同一个用户，读得到；这样不用把字节经服务转一遍）。受保护的不交。
- Mac 上文字文件的预览是应用自己画的服务给的前 64 KB（不是 Quick Look），长行同样按栏宽换行。
- 别的节点上的文件：文字和图片用 `/files/preview`；要 Quick Look 时 `/files/content` 下到应用的临时目录（随应用退出删掉）。
- 从 Finder 拖进来的、本机文件栏里选的，用 Mac 应用里的同一张表就地判断（`AgentSwitchMacCore/Files/FilesSensitive.swift`，与服务的 `sensitiveReason` 一条条对应，各有测试），不必为每个文件问服务；别的节点上的文件听那个节点的服务（`/files/stat` 的 `sensitive`）。

### 7.3 安全边界

- **只读**：第一版没有写的接口。
- **AgentSwitch 自己的禁区**：与调度执行器的读禁区同一张表（`protected.ts` 的 `defaultProtected().readDenied`：凭据网关的目录与 socket、浏览器会话档案与共用浏览器的状态目录、远程监听的 TLS 目录、本地令牌、节点目录；2026-10-20 起还有配置目录 `profiles/`，Codex 账号配置的登录存在那里，profiles-v0 §6.2）。在里面或就是它：列出时只有名字和 `locked`，没有大小、时间、内容；`stat`、`preview`、`content`、`{path}` 附件一律 403。终端里的禁区表更宽松（`terminalProtected`，只关网关和节点），这里不用它：文件栏会把内容送到手机上。任何授权范围里它们都锁着。
- **可能含凭据的文件**（用户定：看就行，给 agent 时提醒；第一稿 §10.4 问过要不要把它们也锁上）：照常列出、预览（手机也能），`/files/stat` 带 `sensitive: {reason}`；给 agent 时界面问一次（§4）。只按路径和名字判断，不读内容找密码。
  - 文件夹：`~/.ssh/`（`*.pub`、`config`、`known_hosts` 除外）、`~/.gnupg/`、`~/Library/Keychains/`。
  - 文件：`~/.aws/credentials`、`~/.netrc`、`~/.git-credentials`、`~/.npmrc`、`~/.pypirc`、`~/.docker/config.json`、`~/.kube/config`、`~/.config/gh/hosts.yml`；各 agent 自己存登录的文件（`~/.codex/auth.json`、`~/.claude/.credentials.json`、OpenCode 与 pi 的登录文件，位置照 agents-v0）；各配置自己的登录目录（profiles-v0）。
  - 名字（在哪都算）：`.env`、`.env.*`（`.env.example`、`.env.sample`、`.env.template` 除外）、`*.pem`、`*.key`、`*.p12`、`*.pfx`、`*.keychain-db`，和不带 `.pub` 的 `id_rsa`、`id_ecdsa`、`id_ed25519`。
- **先求真实位置再判断**：每个路径 `realpath` 之后再对表；符号链接按目标判断，指向禁区的链接照“受保护”显示，指向敏感文件的照“敏感”问；`..` 和相对路径不收。
- **远程调用**（手机、别的节点）：`/files…` 加进远程表，受 §7.5 的开关和范围管；`content` 有大小上限；每次远程读文件内容记一行审计（设备、路径、字节数，**不记内容**）。日志里只有路径。
- **凭据不进执行器**：文件栏给 agent 的只是路径；agent 读不读得到由它自己的禁区决定（调度执行器、终端各按各的表），这里不替它打开任何东西。
- **系统的访问权限**：服务以登录用户运行，读“桌面”“文稿”“下载”、外置盘、网络盘时 macOS 会对 AgentSwitch 问一次（TCC）；拒绝后回 `{error: "permission"}`，界面照 §3.3 说明。
- 改这些入口时同步更新 `packages/secret-gate/BOUNDARY.md`（文件内容第一次经服务到手机；授权范围）。

### 7.4 别的节点

- 窗口在别的节点上时，文件栏的请求发给那个节点（远程表里的同一组 `/files…`）；Linux 节点没有 Quick Look 缩略图，图片的 `preview` 退回原图（≤ 5 MB）或只给信息。
- 手机连着几个节点时（mesh-v0 §5.1），`Files` 标签跟着当前那台，`Files on Mac` 用的是这个终端所在的那个节点。

### 7.5 授权范围

用户（看过第一稿，问的是“手机、别的节点读这台 Mac 的文件，要不要有节点自己的开关”）：可以，并且可以设置给其他节点设置授权文件范围。

- **节点自己的开关**：`Settings › Nodes` 的 `This Mac` 一组，`Paired Nodes May Type` 下面加 `Paired Nodes May Read Files`，默认开。关掉以后，配对的设备（手机、别的节点）的 `/files…` 和 `{path}` 附件一律回 403 `{error: "files-off"}`，它们那边写“Mac mini 不允许配对的设备读取文件。可在 Mac mini 的“设置 › Nodes”中打开。”。本机的应用不受影响。
- **每个设备一个范围**：`Nodes` 里每个配过对的节点或手机，`It Uses This Mac` 下面多一行 `Files`，一个弹出菜单：
  - `Home Folder`（新配对的设备默认这一档）：家目录和它下面的一切。
  - `All Files`：服务所在账户能读的一切（`/`、外置盘）。
  - `Selected Folders`：只有列出的几个文件夹。选了它，下面一行行列出这几个文件夹，每行一个 `−`，末尾 `Add Folder…`（用 Mac 的面板选）。
  - `None`：不给读；那边写“Mac mini 没有给这台设备读取文件的权限。”。
  - `It Uses This Mac` 关着的行没有这一行（本来就连不进来）；开关关着时这一行变灰。
- **范围外是什么样**：路径照样每层可点。范围之上的那几层（比如只给了 `~/Projects/lumen` 时的 `/`、`/Users`、`/Users/you`、`~/Projects`）只列通往授权文件夹的那几个，其余不列，底部写“仅显示授权范围内的项目。”。直接请求范围外的路径（`Go to Folder…`、记着的位置）回 403 `{error: "scope"}`，界面写“此文件夹不在 Mac mini 给这台设备的授权范围内。”，`Home` 回到范围里第一个能去的地方。
- **管到哪**：`/files`、`/files/stat`、`/files/preview`、`/files/content` 和 `{path}` 附件。判断用 `realpath` 之后的路径：范围里的链接指到范围外，按范围外算。
- **管不到的**（设置里的说明照写）：范围不是沙箱。配对的设备照样能开终端，在终端里让 agent 读别的地方——配对的设备本来就等于能以用户身份在这台 Mac 上跑命令（mesh-v0 §6 第 1 条）。范围管的是文件栏和附件能看到、能交出去的。设置里那一组下面写：“范围只限制其他设备在文件栏中能浏览和附加的文件。配对的设备仍可在终端中让 agent 读取其他位置。”。
- **谁定**：只在这个节点自己身上定（mesh-v0“各管各的”）：Mac 在设置里；Linux 节点用命令行：`agentswitch devices files <设备> home|all|none|<文件夹>…`、`agentswitch settings files on|off`（第二步）。范围存在 `mesh.json` 的 `scopes` 里，按设备号。
- 用别的节点时，主窗口文件栏的标题写 `@ Mac mini`，范围是 Mac mini 给这台 Mac 的那一份。

### 12.2 Mac 的文件栏

- **新建**：标题行 `⌂` 后面加 `+`，菜单 `New File…  ⌥⌘N`、`New Folder…  ⇧⌘N`（下拉菜单里写快捷键）。右键一个文件夹也有这两项，放在 `Add to Reply` `Open` 下面一组（VS Code 放在最前；这里最常用的还是给 agent，Apple 说常用的放前面）；列表空白处右键是这一层的菜单，这两项在最前。建在哪：右键的那个文件夹（文件夹看法里先进到它）；用 `+` 或键时，像素的树照 VS Code——选中的是文件夹就建在它里面，是文件就建在它旁边，没选中就建在当前文件夹；经典的文件夹看法照 Finder，建在当前这一层。
  - **就地输入**：像素的树里那个文件夹展开，第一行出一个输入框（前面是 `▸` 或文件的位置，名字后面跟着 `/` 表示文件夹）；经典的文件夹看法里在这一层最上面出一行（文件夹或文件图标加输入框）。
  - 一边输一边检查，出错时输入框下一行红字，`↩` 不响：`请输入名称。`、`此位置已有“src”。请换一个名称。`、`名称不能是“.”或“..”。`；首尾有空格是琥珀色的一行 `名称前后有空格。`，照样能建（VS Code 也只提醒）。
  - `↩` 建，`esc` 取消；点到别处时名字有效就建、无效就取消（VS Code 的做法）。名字里带 `/` 一次建几层（`src/utils/date.ts`：缺的 `src/`、`utils/` 一并建）。
  - 建好以后选中它（文件夹不进去）；新文件的预览写“此文件为空。”，`Open` 交给默认程序。以 `.` 开头而隐藏文件没显示时照样建，底部一行“已创建“.env”。它是隐藏文件，可在 ⋯ › Show Hidden Files 中显示。”
- **改名**（用户定，§12.7 第 2 条）：右键 `Rename…`，或选中后按 `↩`。名字原地变成输入框，选中主名（不含扩展名，文件夹选全名），检查同上；`↩` 改，`esc` 不改。
  - 第一步把 `↩` 定成“打开”，是因为当时没有改名（§3.4）；现在照 Finder 和 VS Code 改成改名，打开是双击、`⌘↓`（Finder）或 `⌘O`。
- **移到废纸篓**：右键最后一项 `Move to Trash`，或 `⌘⌫`；多选一起移。**不问**（Apple 的规矩；用户定，§12.7 第 1 条）；底部那一行几秒内写“已将“notes.md”移到废纸篓。⌘Z 可放回。”；`⌘Z` 放回原处，选中并滚到它。
  - 要问的只有两种：
    - **只能永久删除**（这个盘放不进废纸篓：一些网络盘、外置盘）：“无法将“x”移到废纸篓。要永久删除吗？此操作无法撤销。”`[ Cancel ]` `[ Delete Permanently ]`——VS Code 的同一问。
    - **有终端正在里面运行的文件夹**（就是它的文件夹，或在它下面）：“终端“lumen”正在此文件夹中运行。移到废纸篓后，其中的 agent 仍会使用原来的路径，可能出错。”`[ Cancel ]` `[ Move to Trash ]`。改名也问同一种，最后一句换成“改名后……”、按钮 `Rename`。
  - **动不了的**，菜单里不出现，按键不响，底部一行说为什么：AgentSwitch 自己的禁区（§7.3），**和装着禁区的文件夹**——家目录、`~/Library`、`~/Library/Application Support` 这一串，移走它们就把 AgentSwitch 的凭据一起搬走了；`/` 和系统的顶层文件夹（系统本来也不让）。说明：“此文件夹中有 AgentSwitch 的凭据，不能在这里改名或移到废纸篓。”
  - 不做永久删除（`⌥⌘⌫`）：要清就去 Mac 的废纸篓里清。
- **撤销**：`⌘Z` 撤这一栏里做过的新建（把新建的移到废纸篓）、改名（改回去）、移到废纸篓（放回原处），`⇧⌘Z` 重做；按节点各记一串，应用退出就清。原处已有同名的就不放回，说明“原位置已有“x”，未放回。可在废纸篓中手动放回。”
- **这一轮不做**：剪切、拷贝、粘贴，拖着移动，`Duplicate`，`Open With`。
- **右键菜单顺手改的**（Apple 的右键菜单规范）：不写快捷键；用不了的项不出现，而不是变灰——`Copy Relative Path` 只在它在焦点那一块终端的文件夹下面时才有，没有回复框的页面上没有 `Add to Reply`。第一步的原生菜单本来就没写快捷键，第二稿的演示写了，这一稿去掉。
- **别的节点**：同样的菜单和键，经那个节点的服务做；它的禁区它自己判断。窗口在别的节点上时，`⌘Z` 撤的也是那个节点上的。

### 12.5 服务

| 接口 | 做什么 |
|---|---|
| `POST /files/folder` `{path}` | 新建文件夹；`path` 是新文件夹的绝对路径，中间缺的层一并建。已有回 409 `exists` |
| `POST /files/file` `{path}` | 新建空文件，中间缺的层一并建。已有回 409 `exists` |
| `POST /files/rename` `{path, name}` | 在同一个文件夹里改名；`name` 不含 `/`。已有回 409 `exists` |
| `POST /files/trash` `{paths, permanent?, force?}` | 移到废纸篓，回 `{moved: [{path, trashed}]}`（`trashed` 是废纸篓里的位置，撤销用）。放不进废纸篓回 409 `no-trash`，问过以后带 `permanent: true`；有终端在里面运行回 409 `in-use {terminals}`，问过以后带 `force: true`（改名同样带 `force`） |
| `POST /files/restore` `{trashed, path}` | 撤销移到废纸篓：放回原处。原处已有回 409 `exists` |

- **检查**：一律先 `realpath`（新建的看它的上一层）；禁区、装着禁区的文件夹、`/` 与系统顶层回 403 `locked`；名字空、`.`、`..`、含 NUL 回 400 `bad-name`；远程调用受 §7.5 的开关和范围管——范围外回 403 `scope`，读得到的地方才改得了。
- **Mac 上移到废纸篓**：系统自己的 `NSFileManager.trashItem`（和 Finder 同一个），经每台 Mac 都有的 `osascript` 脚本桥调用，不必另带工具。做的时候发现：脚本桥读这个方法的“放到了哪”那个出参会让脚本崩掉（2026-10-18），所以只让它移，再由服务在那个盘的废纸篓里按设备号和 inode 找回它（同一个盘里移动 inode 不变），撤销要的就是这个位置。系统自带的 `/usr/bin/trash` 不用：它从 macOS 15 才有（应用最低支持 14），也不说放到了哪。**Linux 节点**照 freedesktop 的废纸篓规范（`~/.local/share/Trash/files` 加 `.trashinfo`）自己搬；同一个盘上放不进的回 `no-trash`。
- **远程改文件的总闸**：`Settings › Nodes` 的 `This Mac` 一组，`Paired Nodes May Read Files` 下面加 `Paired Nodes May Change Files`，默认开；读的开关关着时它也灰。关着时配对的设备调这几个接口回 403 `changes-off`，它们那边那几项不出现。默认开的理由：配对的设备本来就能在终端里以用户身份做这些（mesh-v0 §6 第 1 条），这个开关是“文件栏里不许改”的总闸，不是沙箱。
- **审计**：每次改动（本机和远程）记一行：设备、动作、路径，不记内容。
- 同步更新 `packages/secret-gate/BOUNDARY.md`：服务第一次有写文件的接口。

用户：能不能直接扩展现有的文件栏功能 支持到linux的网页控制台。

来由：PR #7 想在终端旁边开 yazi 看 agent 做出的文件，并给配对节点一个开关。yazi 能执行命令（`!`、`:`、用程序打开文件），开关一开等于把这台机器的账户交给配对节点，每设备的文件范围、敏感文件那一问、受保护路径都管不到它。用户定：不用 yazi，按钮照旧，打开的是文件栏。Mac 上这已经有了（标题栏和顶栏的文件夹图标、`⌘⇧F`、右键 `Show in Files`）；缺的是没有窗口的节点——它本机的界面只有网页控制台，那里没有文件栏。

- **哪里有**：浏览器里的终端页（`/ui/terminal.html`）。顶栏多一个文件夹图标（开着时是信号色），终端行的右键菜单多一项 `Open Files Beside`，`⌘⇧F` 开关。都停在这个终端**当前**所在的文件夹（`workdir`，没有就用启动时的）；没有终端时从主目录开始。Mac 窗口里不出现——它有自己的文件栏。
- **样子**：屏幕右边一栏，可拖宽（双击还原），窄屏上盖住整页。上面一行路径，每层可点；中间是目录树；选中文件后下面是预览：文本和代码显示开头的部分，图片用缩略图，别的写明不在这里预览；都有 `[ Download ]`。`Name` / `Date Modified` 切换排序（按时间时每行写多久前，方便找 agent 刚写的文件），`.*` 显示隐藏文件。开着时每 4 秒问一次，没变的文件夹服务回 304。演示页 `docs/design/concepts/files-console.html`。
- **键**：同 Mac 的文件栏——`↑` `↓`、`Home` `End`、`→` 展开、`←` 收起或到上一层、`↩` 或 `⌘↓` 进入文件夹、`⌘↑` 到上一层、打字母跳到那个文件、`esc` 把键盘还给终端。打开这一栏时键盘在目录树上。
- **权限**：只用已有的 `GET /files`、`/files/stat`、`/files/preview`、`/files/thumbnail`、`/files/content`，服务没有改动，没有新开关。网页控制台登录后是本机身份：看得到这个账户能看到的文件，AgentSwitch 自己放凭据的位置照旧只给名字（`Locked`）。没有任何执行命令的入口。
- **第一步没做的**：新建、改名、移到废纸篓（§12 的接口都在，界面没接）；把文件放进回复；拖进来的文件。
- **实现**：规则在 `packages/daemon/ui/lib/filesTree.js`（纯逻辑，`tests/filesTree.test.ts`），画在 `ui/lib/filesColumn.js`，接线在 `ui/terminal.js`（`files`、`toggleFiles`），样式在 `ui/terminal.css`。
- **验证**：临时服务（干净环境、草稿目录）上在共用浏览器里点过：图标和 `⌘⇧F` 开关、方向键、`↩` / `⌘↓` 进入、展开、打字母跳转、文本和图片预览、两种排序、隐藏文件、往文件夹里写一个新文件后 5 秒内出现。**没验证**：终端行的 `Open Files Beside`（临时服务上没有装 agent，开不出终端）、打开这一栏时终端画面的重排、窄屏、经典外观、真的 Linux 节点。
